# MIPS SAD Block Matching

Collaborative computer architecture project implementing a block-matching
algorithm in MIPS assembly using Sum of Absolute Differences (SAD).

## Highlights

- MIPS assembly implementation
- Explicit memory addressing and register management
- Nested loops and branching
- Zig-zag search traversal
- FPGA validation using a Digilent Nexys A7
- Team-based development and debugging
