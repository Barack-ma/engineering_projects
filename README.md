# University OOP Model (ECE373)

Java implementation of a small University system demonstrating **OOP design**, **package organization**, and **schedule conflict detection**.

## Features
- Students & Professors with schedules and conflict detection
- Courses with rosters, professor assignment (one per course), and classroom scheduling
- Departments & University aggregation with list/report methods
- Drivers to run and verify behavior

## Package Structure
- \org.university.hardware\ – \Classroom\, \Department\
- \org.university.people\ – \Student\, \Professor\
- \org.university.software\ – \Course\, \University\, Drivers

## How to Run
- Open in your IDE (Eclipse/IntelliJ) or compile via \javac\.
- Run the driver(s) in \org.university.software\ to see schedules and outputs.

## Concepts Demonstrated
Encapsulation, object relationships (associations & multiplicity), ArrayList usage, sorting, and conflict checks.
